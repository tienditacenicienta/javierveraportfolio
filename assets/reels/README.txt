REELS PARA LOS IPHONE LATERALES
Cuando tengas tus videos, colócalos aquí con estos nombres:
- reel-01.mp4
- reel-02.mp4

Formato recomendado: MP4 con video H.264, vertical 9:16 (ideal 1080 x 1920).
Duración sugerida: 5–15 segundos, optimizados para web y sin audio obligatorio.
Los videos deben estar muted/loop/playsinline para que funcionen como reels decorativos.
Si los archivos todavía no existen, la web muestra la composición ilustrativa como placeholder.
